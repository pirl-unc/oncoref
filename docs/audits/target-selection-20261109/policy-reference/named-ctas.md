# Named CTA families and studied targets

This explicit panel contains 113 protein records from the named MAGE-A/B/C, SSX, GAGE, PAGE, XAGE, BAGE, CT45/47, SPANX, TSPY and CSAG families, plus individually listed targets. SSX2IP is not an SSX antigen-family member and is excluded from this panel. BAGE has no resolved record in the current reference identity catalog; no category is inferred for that missing identity. Family membership and historical nomination do not override a normal-expression exclusion. The table uses current protein records, so identical-reference loci can share a row. The CSV retains every member gene, transcript and paper link.

Current means the corrected fivefold-rule draft; proposed means the tenfold single-tumor alternative. The two-patient route is unchanged. Unsafe records retain the existing normal/clinical screen. Gate names identify the recorded cause; they do not assert that clinical injury has been proved for every protein. The current [full inventory](../rebuild/report.html) includes proteins outside this named panel.

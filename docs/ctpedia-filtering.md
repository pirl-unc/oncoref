# How CTpedia genes are classified and filtered

This is the dated 1.38.0 threshold audit. See the [current catalog](target-selection.md)
and [1.39.0 changes](cta-release-1.39.0.md) for library QC and revised memberships.

Generated by `scripts/build_cta_threshold_review.py` from the 1.38.0 catalog (policy `oncoref.target-selection.2026-11-15.1`, filters `oncoref.target-filters.2026-11-15.1`).

oncoref's CTA reference tags 209 genes as CTpedia. They are 195 catalog proteins, because loci with identical selected sequences count as one protein. CTpedia tags have no primary-paper status ([sources](cta-landscape-sources.md)); they are a reference list, not evidence the catalog uses.

Every protein below lists **every** check it fails, not only the one that decides its category. A protein that is out for several independent reasons says so. For Unsafe and otherwise ineligible proteins the catalog never runs the tumor comparison; this page runs the catalog's own comparison for them and marks the result *if assessed*.

## The checks

- **Unsafe**: replicated normal-tissue RNA, rare normal-cell RNA, published normal expression or protein in a non-reproductive tissue ([target selection](target-selection.md)).
- **No tumor at 10x**: no non-germ-cell tumor sample reaches 10 x max(highest non-reproductive normal, Disposable, 1 TPM). Germ cell tumors are reported, never counted.
- **No reproductive evidence**: no adult reproductive, reproductive-cell, IHC, reviewed-protein or developmental RNA route.
- **Sequence**, **identity**, **coverage**, **evidence unresolved**: the shared eligibility checks.
- **Filters**: `loose`, `standard` and `strict` remove Target candidates by layer; every failing layer is listed ([filters](target-filters.md)).

## Filter modes

- `loose` keeps 111 CTpedia proteins; layers that remove candidates: papers 9.
- `standard` keeps 91 CTpedia proteins; layers that remove candidates: papers 28, off-target TPM 2.
- `strict` keeps 50 CTpedia proteins; layers that remove candidates: papers 48, set 21, name exclusion 15, off-target TPM 4, curated tier 1.
